# คู่มือตั้ง task "007DBFSyncFast" ที่เครื่องสาขา (ทำครั้งเดียวต่อเครื่อง ประมาณ 5 นาที)

**ทำไมต้องตั้ง:** เครื่อง Express ที่สาขาส่งไฟล์บิลขึ้น Google Drive ทุก 15 นาที แอปปิดรอบจึงเห็นบิลช้าสุด 15 นาที
task ใหม่นี้จะส่งถี่ขึ้นเป็น **ทุก 2 นาที เฉพาะช่วง 16:00–17:00** (ช่วงปิดรอบ) ช่วงอื่นเหมือนเดิม
task เดิม (007DBFSync) ยังอยู่ ไม่ถูกแก้หรือลบ

**ทำที่เครื่องไหน:** เครื่อง Windows ที่ลง Express และมี Google Drive ของสาขา (เครื่องเดียวกับที่เคยตั้ง 007DBFSync)
สาขาละ 1 เครื่อง: บึงกาฬ (BK) · สกลนคร (SKN) · โพนพิสัย (PPS)

---

## วิธีทำ (ไม่ต้องพิมพ์คำสั่งเอง)

1. ที่เครื่องสาขา เปิด File Explorer ไปที่โฟลเดอร์ Google Drive ของสาขา →
   `All_on_Cloud` → `AutoExport` → `scripts`
   (เครื่อง SKN ปกติคือ `E:\007skn\All_on_Cloud\AutoExport\scripts` · BK คือ `E:\007sbk\...`)
2. หาไฟล์ **`install_fast_sync.bat`**
3. **คลิกขวา** ที่ไฟล์ → เลือก **Run as administrator** → ถ้าถามยืนยัน (User Account Control) กด **Yes**
4. หน้าต่างดำจะรันเอง 4 ขั้น รอจนขึ้น **`========== เสร็จแล้ว ==========`**
5. ดูบรรทัด **"ผลล่าสุดใน <สาขา>:"** ต้องเป็นวันเวลาเมื่อสักครู่ → ใช้ได้ กดปุ่มใดก็ได้ปิดหน้าต่าง
6. ถ้าขึ้นบรรทัดที่มี **X** หรือเวลาไม่ใช่เมื่อสักครู่ → **ถ่ายรูปหน้าจอทั้งหน้าส่ง CTO** แล้วปิดหน้าต่างได้เลย ยังไม่ต้องทำอะไรต่อ

เสร็จแล้วแจ้ง CTO ว่า "สาขา ___ ตั้ง Fast แล้ว" CTO จะเช็คจากฝั่ง Mac mini ให้ว่าไฟล์เข้าถี่ขึ้นจริงตอน 16:00–17:00

---

## ถ้าหาไฟล์ install_fast_sync.bat ไม่เจอ

ไฟล์อยู่ใน Google Drive โฟลเดอร์ `scripts` ถ้ายังไม่ขึ้น ให้รอ Drive sync สักครู่ หรือคลิกขวาที่ไอคอน Google Drive ตรงมุมขวาล่างแล้วดูว่ากำลัง sync อยู่ไหม

## วิธีตรวจทีหลังว่า task ยังอยู่

เปิด **Task Scheduler** (พิมพ์ในช่องค้นหาของ Windows) → Task Scheduler Library → ต้องเห็นทั้ง `007DBFSync` และ `007DBFSyncFast`
คอลัมน์ Next Run Time ของ Fast จะเป็นเวลา 16:00 ของวันถัดไป (หรือภายใน 2 นาที ถ้าตอนนี้อยู่ในช่วง 16:00–17:00)

## ถ้าต้องการยกเลิก

เปิด Command Prompt แบบ Run as administrator แล้วพิมพ์
```
schtasks /delete /tn 007DBFSyncFast /f
```
task เดิม 007DBFSync ไม่ได้รับผลกระทบ

---

*สำหรับ CTO:* สคริปต์อ่าน action และผู้รันจาก task เดิมด้วย PowerShell `Get-ScheduledTask` แล้วสร้าง task ใหม่ด้วย
`schtasks /create /tn 007DBFSyncFast /tr "<action เดิม>" /sc daily /st 16:00 /ri 2 /du 01:00` · รายละเอียดและข้อควรระวังอยู่ใน `prod-feeder/CTO_SETUP.md`
